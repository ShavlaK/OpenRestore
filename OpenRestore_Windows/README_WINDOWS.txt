  ⚡ OpenRestore v1.6.0 — Windows Edition (Standalone x64)

ПЕРВЫЙ ЗАПУСК И ИНСТРУКЦИЯ:

1. ТРЕБОВАНИЯ:
   Для работы с iPhone на Windows требуется официальный iTunes от Apple:
   - Если iTunes не установлен, скачайте его:
     https://www.apple.com/itunes/download/win64
   (Это необходимо для драйверов Apple Mobile Device Service).

2. ЗАПУСК:
   - Просто дважды кликните по «OpenRestore.exe».
   - Приложение откроется в отдельном красивом окне (через Microsoft Edge / Chrome).

3. ВОЗМОЖНОСТИ:
   📱 Устройства: Автоматическое распознавание iPhone по кабелю (USB) и Wi-Fi.
   ☁️ Покупки Apple ID: Вход в аккаунт с поддержкой 2FA, постраничная загрузка всех 600+ покупок.
   🔢 Произвольный ID: Скачивание любого приложения по Adam ID (например, 1467701468 для Au).
   📚 Библиотека IPA: Хранилище загруженных файлов в папке Downloads\OpenRestore с установкой в 1 клик.
   📊 Живой прогресс-бар: Отображение точных процентов загрузки и установки на iPhone.

Приятного использования!
