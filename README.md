**OpenRestore** — мощный, 100% бесплатный и полностью открытый инструмент для восстановления, скачивания и установки любых удалённых или скрытых приложений из App Store (Сбер, Т-Банк, ВКонтакте, 2ГИС, Альфа-Банк, ВТБ, Яндекс Банк, Ozon Банк, Wildberries и др.) на iPhone и iPad.

Полная, независимая и бесплатная альтернатива утилитам вроде **bmrng**, не требующая покупки токенов, подписок или передачи данных на сторонние сервера.

---

## 🌟 Ключевые возможности

- 🚀 **100% Бесплатно и локально:** Никаких закрытых API, токенов, скрытых платежей или рекламы. Весь процесс происходит исключительно между вашим Mac, Apple ID и серверами Apple.
- 🔒 **Официальный FairPlay DRM:** Приложения скачиваются напрямую с официальных CDN Apple и содержат подлинную цифровую подпись вашего Apple ID (`SC_Info`).
- 🤖 **Полная автоматизация Apple Configurator:** OpenRestore самостоятельно управляет интерфейсом Configurator — нажимает меню, вводит запросы, выбирает элементы в сетке и закрывает системные диалоги («Skip App» / «Stop») без участия человека.
- 📦 **Пакетная выгрузка всей библиотеки (Batch Mode):** Восстановление 10, 20 или 50 приложений подряд в один клик.
- 📲 **Прямая установка IPA на iPhone:** Высокоскоростной USB-инсталлятор с живым отображением логов и прогресс-бара.
- 🛡️ **Гарантия сохранности данных (Shield Guarantee):** Установка новых приложений абсолютно безопасна для устройства — личные данные, фото, контакты, переписки и существующие приложения не затрагиваются.
- 🗂️ **Локальная Библиотека IPA:** Автоматическая организация и хранение всех загруженных пакетов в `~/Downloads/OpenRestore/` для повторной установки в 1 клик на любые ваши устройства.

## 📋 Системные требования

1. **Mac** под управлением **macOS 12.0 (Monterey) или новее** (поддерживаются как Apple Silicon M1/M2/M3/M4, так и процессоры Intel).
2. **Apple Configurator** (бесплатно из Mac App Store).
3. **iPhone / iPad**, подключенный кабелем к Mac.

## 🚀 Быстрый старт

### Способ 1: Готовое приложение
1. Скачайте последний релиз из раздела [Releases](https://github.com/).
2. Запустите **`OpenRestore.app`** (или дважды кликните `OpenRestore.command`).
3. При первом запуске выдайте разрешение **«Универсальный доступ»** в настройках macOS (*Системные настройки → Конфиденциальность → Универсальный доступ*).

### Способ 2: Сборка из исходников
```bash
git clone https://github.com/your-repo/OpenRestore.git
cd OpenRestore
./build_app.sh
open OpenRestore.app
```

## 🏗 Архитектура проекта

```text
OpenRestore/
├── OpenRestore.app/            # Собранное нативное приложение macOS
├── native_app/                 # Исходный код на Swift (SwiftUI)
│   ├── App.swift               # Точка входа приложения
│   ├── ConfiguratorEngine.swift# Движок взаимодействия с кэшем и UI Configurator
│   └── ContentView.swift       # Главный пользовательский интерфейс и панели
├── bin/
│   └── ipatool                 # Вспомогательный модуль прямой загрузки
├── catalog.json                # База данных популярных приложений и Adam ID
├── ios_core.py                 # Прямой USB-канал связи с iOS (pymobiledevice3)
├── build_app.sh                # Скрипт сборки и генерации сертификата
├── openrestore.command         # Скрипт быстрого запуска
└── release_pack.sh             # Скрипт создания DMG и ZIP релизов
```
