**OpenRestore** — мощный, автономный, 100% бесплатный и полностью открытый (Open-Source) инструмент для macOS, предназначенный для восстановления, скачивания и установки любых удалённых или скрытых приложений из App Store (СберБанк, Т-Банк, ВКонтакте, 2ГИС, Альфа-Банк, ВТБ, Яндекс Банк, Ozon Банк, Wildberries и др.) на iPhone и iPad.

Проект является полноценной, независимой и полностью локальной альтернативой коммерческим утилитам (вроде *bmrng*), не требует покупки токенов, подписок, ключей активации и не передаёт данные на сторонние серверы.

---

## 🌟 Ключевые возможности

### ⚡ 1. Два независимых движка работы (Dual Engine)
- **⚡ Прямой нативный режим (Direct Mode / По умолчанию):** 
  - Прямое взаимодействие с серверами App Store через встроенный модуль `ipatool`.
  - Полноценная поддержка авторизации Apple ID с двухфакторной аутентификацией (**2FA**).
  - Изолированная связка ключей (`openrestore_passphrase_v1`) — не запрашивает системный пароль macOS и не блокирует получение 2FA-кодов.
  - Автономная загрузка официальных зашифрованных IPA-пакетов с подлинной цифровой подписью FairPlay DRM (`SC_Info`).
- **🍏 Режим Apple Configurator (Configurator Mode):**
  - Альтернативный режим для работы через официальную утилиту Apple Configurator.
  - Автоматическое считывание локального кэша и базы данных SQLite.
  - Полная автоматизация UI-действий (клики по меню, закрытие диалогов «Skip/Stop»).

### 📱 2. Менеджер устройств в стиле iMazing (Device Manager)
- **Умное определение типа связи:**
  - 🟢 **USB (Кабель):** Зеленый индикатор прямого проводного соединения (максимальная скорость передачи).
  - 🔵 **Wi-Fi сеть:** Синий индикатор локальной беспроводной синхронизации.
  - ⚪ **История (Офлайн):** Список ранее подключенных устройств («Не в сети»).
- **Детальная информация об устройстве:** Распознавание имени владельца, точной модели iPhone/iPad, версии iOS, уровня заряда аккумулятора и объёма накопителя.
- **Управление сопряжением:** Функция **«Забыть устройство»** для безопасного сброса пары (`unpair`) и очистки истории в приложении.

### ☁️ 3. Покупки Apple ID с поддержкой пагинации 600+ приложений
- **Фоновая многостраничная загрузка:** Автоматическая постраничная подгрузка всей истории покупок (без ограничения в 100 приложений).
- **Мгновенное кэширование:** История сохраняется в локальный кэш `purchases_cache.json` — повторный запуск приложения происходит мгновенно (0.01 сек).
- **Динамический счетчик:** Отображение реального прогресса загрузки покупок в реальном времени `(100/691)`.

### 📊 4. Плавный потоковый Прогресс-бар в реальном времени
- **Реальные проценты:** Асинхронный перехват вывода консоли (`stdout/stderr`) с отображением точного процента:
  - `0% – 70%`: Прогресс скачивания зашифрованного пакета с серверов Apple CDN.
  - `70% – 100%`: Прогресс распаковки, проверки подписи FairPlay DRM и установки на iPhone.
- **Информативные статусы:** Динамическое текстовое отображение этапа («Загрузка... 45%», «Установка на iPhone... 82%»).

### 🔢 5. Восстановление по произвольному Adam ID
- Загрузка любого официального приложения по его числовому идентификатору (например, `1467701468` для приложения «Au»).
- Автоматический поиск метаданных (название, иконка высокого разрешения) через iTunes API (RU/US регионы).

### 📚 6. Локальная библиотека IPA (Local Library)
- Автоматическая каталогизация всех загруженных приложений в `~/Downloads/OpenRestore/`.
- Автоочистка поврежденных и временных файлов (<500 КБ).
- **Пакетная установка (Batch Install):** Выбор нескольких IPA и их последовательная установка на iPhone в один клик.

### 🛡️ 7. Гарантия безопасности (Shield Guarantee)
- **100% сохранность данных:** Установка приложений через системный сервис `MobileInstallationService` iOS не затрагивает личные данные, переписки, фото, контакты и другие приложения.
- **Подлинные подписи:** Приложения привязываются к вашему личному Apple ID и работают стабильно без риска отзыва сертификатов корпоративных профилей.

## 🖥 Системные требования

- **Операционная система:** macOS 12.0 Monterey, macOS 13 Ventura, macOS 14 Sonoma, macOS 15 Sequoia или новее.
- **Архитектура:** Apple Silicon (M1/M2/M3/M4) и Intel (x86_64) — единый бинарный файл Universal 2.
- **Устройство:** iPhone, iPad или iPod Touch под управлением iOS 12.0 – iOS 18.x+.
- **Подключение:** USB-кабель (Lightning / Type-C) или локальная сеть Wi-Fi.

## 🚀 Быстрый старт

### Вариант 1: Установка готового приложения (Рекомендуется)
1. Скачайте последнюю версию **`OpenRestore-v1.6.0-Universal.dmg`** из раздела [Releases](https://github.com/ShavlaK/OpenRestore/releases).
2. Откройте DMG-образ и перетяните `OpenRestore.app` в папку `Программы` (`Applications`).
3. Запустите приложение.
4. *(Опционально для режима Configurator)*: При первом запуске выдайте разрешение **«Универсальный доступ»** в настройках Mac (*Системные настройки → Конфиденциальность и безопасность → Универсальный доступ*).

### Вариант 2: Сборка из исходников

```bash
# 1. Клонирование репозитория
git clone https://github.com/ShavlaK/OpenRestore.git
cd OpenRestore

# 2. Сборка Universal 2 приложения
./build_app.sh

# 3. Запуск
open OpenRestore.app
```

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>Вопрос: Почему приложение закрывается сразу после установки на iPhone?</b></summary>
<br>
Все официальные приложения из App Store защищены FairPlay DRM и зашифрованы персональным ключом вашего Apple ID. Чтобы приложение запустилось на iPhone, на устройстве должен быть выполнен вход в <b>тот же самый Apple ID</b> (в Настройках или App Store), с которого производилось скачивание в OpenRestore.
</details>

<details>
<summary><b>Вопрос: Зачем нужен USB-кабель, если есть Wi-Fi?</b></summary>
<br>
Установка по Wi-Fi полностью поддерживается и происходит внутри вашей локальной сети. Однако процесс установки включает расшифровку пакета и валидацию цифровых подписей процессором iPhone. По кабелю передача данных происходит со скоростью 480 Мбит/с – 10 Гбит/с с нулевой сетевой задержкой, что ускоряет установку в 5–10 раз.
</details>

<details>
<summary><b>Вопрос: Безопасно ли вводить пароль Apple ID в приложении?</b></summary>
<br>
Да. OpenRestore использует защищённый локальный сессионный ключ Keychain и обращается напрямую к официальным эндпоинтам Apple GrandSlam / StoreKit. Никакие пароли, токены или данные учетной записи не передаются третьим лицам.
</details>
