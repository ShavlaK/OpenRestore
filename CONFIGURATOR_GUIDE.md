# 🛠 Руководство по интеграции и работе с Apple Configurator

Данное руководство подробно описывает внутренние механизмы взаимодействия **OpenRestore** с **Apple Configurator**, требования к операционной системе macOS, права доступа и пошаговую настройку.

---

## 1. Как работает связка OpenRestore + Apple Configurator

Приложения, скрытые или удалённые из российского App Store (например, СберБанк, Т-Банк, ВКонтакте, 2ГИС, Альфа-Банк и др.), невозможно скачать через стандартный поиск App Store на новых устройствах. Однако они остаются навсегда привязанными к вашему аккаунту Apple ID в истории покупок.

**OpenRestore автоматизирует весь цикл захвата и упаковки IPA:**
1. **Инъекция дескриптора покупки:** В локальную SQLite-базу кэша Apple Configurator (`~/Library/Group Containers/K36BKF7T3D.group.com.apple.configurator/Library/Caches/store.sqlite`) внедряется временный тег восстановления `Restore request <Adam ID>` с вашим локальным `DSID`.
2. **Асинхронный поиск и авторизация:** Скрипт автоматизации через macOS Accessibility API активирует окно Configurator, выбирает подключенный iPhone/iPad и открывает диалог `Actions → Add → Apps…`.
3. **Запрос к официальным серверам Apple:** Apple Configurator запрашивает лицензированный FairPlay-пакет у серверов Apple (`buy.itunes.apple.com`).
4. **Перехват и упаковка в `.ipa`:** OpenRestore отслеживает появление временных файлов в директории `TemporaryItems/MobileApps/<UUID>/...`, ждет стабилизации размера и бережно копирует оригинальный FairPlay DRM IPA в Библиотеку (`~/Downloads/OpenRestore/`).
5. **Авто-закрытие системных окон:** При попытке Configurator перезаписать уже установленное на iPhone приложение всплывает модальное окно *«The app named ... already exists»*. Служба `dismissConfiguratorModals()` моментально нажимает **«Skip App»** / **«Stop»**, предотвращая блокировку очереди.

## 2. Первоначальная настройка Apple Configurator

### Шаг 1. Установка Apple Configurator
- Установите официальное бесплатное приложение **Apple Configurator** из Mac App Store.

### Шаг 2. Вход в Apple ID
1. Запустите Apple Configurator.
2. В верхнем меню выберите **Учетная запись → Войти…** (Account → Sign In…).
3. Введите логин и пароль своего Apple ID (с которого ранее приобретались нужные приложения).
4. *Рекомендация:* Скачайте любое одно бесплатное приложение в Configurator, чтобы инициализировать локальный кэш `store.sqlite`.

### Шаг 3. Подключение iPhone / iPad
1. Подключите ваше iOS-устройство к Mac оригинальным кабелем USB / Type-C.
2. Разблокируйте устройство и при появлении запроса нажмите **«Доверять этому компьютеру»** (Trust This Computer).
3. В окне Apple Configurator должно появиться изображение вашего устройства.

## 3. Настройка разрешений macOS (Универсальный доступ)

Для автоматического управления интерфейсом Apple Configurator (клики, ввод поискового запроса, выбор в сетке) приложению OpenRestore необходимы системные права macOS:

1. Откройте **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** (Accessibility).
2. Найдите в списке **OpenRestore** и переведите переключатель в положение **ВКЛ**.
3. Если OpenRestore отсутствует в списке, нажмите `+` внизу и выберите файл `OpenRestore.app`.

> **Примечание:** В OpenRestore встроен постоянный сертификат разработчика, поэтому права доступа сохраняются между перезапусками приложения.

## 4. Режимы работы в OpenRestore

### А. Пакетная загрузка покупок (Batch Mode)
- В разделе **«Покупки Apple ID»** можно отметить галочками нужные приложения (или нажать «Выбрать все») и запустить **«Скачать выбранные»**.
- OpenRestore по очереди обработает каждое приложение, автоматически подтверждая загрузку и закрывая системные диалоги без участия пользователя.

### Б. Прямой режим (App Store Direct)
- Если в настройках включен «Прямой режим», утилита сначала пробует получить пакет напрямую через протокол StoreKit. Если приложение заблокировано или требует ручной привязки, происходит бесшовный автоматический переход на метод Configurator.

### В. Безопасная установка IPA на iPhone
- Установка осуществляется по прямому USB-каналу через сервис `com.apple.mobile.installation_proxy`.
- **Гарантия безопасности:** Установка не затрагивает личные данные, фото, переписки, настройки или другие приложения.
