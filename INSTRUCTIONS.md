# 📖 Инструкция по использованию OpenRestore

## Быстрый старт (Quick Start)

### 1. Запуск приложения
Дважды кликните по **`OpenRestore.app`** (или `OpenRestore.command`) в папке приложения.

---

## 📱 Основные вкладки приложения

### 1. 📲 Устройство (Device)
* Отображает информацию о подключенном iPhone/iPad (Модель, Версия iOS, Серийный номер, UDID).
* Позволяет просмотреть список всех установленных приложений на устройстве с возможностью поиска.
* Кнопка **«Установить IPA на устройство»** позволяет выбрать любой `.ipa` файл на диске Mac и установить его на iPhone.

### 2. 🛍 Каталог (Catalog)
* Содержит готовый список популярных российских приложений, удалённых из App Store (СберБанк, Тинькофф/Т-Банк, ВКонтакте, 2ГИС, Альфа-Банк, ВТБ, Яндекс Банк, Ozon Банк, Wildberries и др.).
* Введите поисковый запрос (например, `Сбер`) или воспользуйтесь фильтрами по категориям.
* Нажмите кнопку **«Скачать в библиотеку»** рядом с нужным приложением.
* Если нужного приложения нет в каталоге, используйте поле **«Поиск по любому Adam ID»** внизу экрана.

### 3. ☁️ Покупки Apple ID (Purchases)
* Автоматически считывает историю покупок вашего Apple ID из кэша Apple Configurator.
* Поддерживает **пакетный режим (Batch Download)**:
  1. Отметьте галочками приложения, которые хотите восстановить.
  2. Нажмите синюю кнопку **«Скачать выбранные (N)»**.
  3. Программа автоматически по очереди скачает каждое приложение, упакует его в официальный `.ipa` и закроет все системные диалоги.

### 4. 📚 Библиотека IPA (Library)
* Локальное хранилище всех сохранённых `.ipa` файлов (по умолчанию `~/Downloads/OpenRestore/`).
* Для каждого приложения отображается размер, дата загрузки и статус FairPlay DRM.
* Кнопка **«Установить»** мгновенно передаёт IPA на подключенный iPhone с отображением живого прогресс-бара и логов установки.
* Кнопка **«Показать в Finder»** открывает файл на Mac.

---

## ⚙️ Настройки и опции
В верхней панели приложения доступны опции:
* **Автоматические клики Configurator:** Включает/выключает скрипт управления окном Configurator (рекомендуется держать включенным).
* **Прямой режим (Direct StoreKit):** Пробует сначала скачать через быстрый протокол App Store перед обращением к Configurator.
* **Папка библиотеки:** Позволяет изменить путь сохранения IPA файлов на внешний накопитель или любую другую папку.

## ❓ Часто задаваемые вопросы (FAQ)

#### Вопрос: Приложение вылетает сразу после установки на iPhone. Что делать?
**Ответ:** Приложения из App Store защищены FairPlay DRM и привязаны к Apple ID. Убедитесь, что на iPhone выполнен вход в тот же Apple ID, под которым приложение скачивалось в Apple Configurator (или приложение хотя бы один раз было загружено в истории этого Apple ID).

#### Вопрос: Безопасна ли установка для личных данных?
**Ответ:** Да, на 100%. OpenRestore использует официальный протокол `MobileInstallationService` iOS. Данные устройства, фотографии, контакты, история сообщений и другие приложения никак не затрагиваются и не удаляются.
