# 📝 История изменений (CHANGELOG)

## [v1.6.0] — 2026-08-30
### 🌟 Ключевые нововведения и улучшения:
- **📊 Потоковый Прогресс-бар в реальном времени:**
  - Внедрен асинхронный перехват потоков `stdout` и `stderr` через `FileHandle.readabilityHandler`.
  - Отображение точных процентов (0% – 70% загрузка с Apple CDN, 70% – 100% распаковка и установка на iPhone).
  - Динамические текстовые статусы («Загрузка... 45%», «Установка... 82%»).
- **☁️ Полноценная пагинация покупок Apple ID (600+ приложений):**
  - Реализован фоновый постраничный опрос (`-p 1`, `-p 2`...) с устранением жесткого лимита в 100 приложений.
  - Динамический счетчик прогресса подгрузки в тулбаре `(100/691)`.
- **⚡ Сверхбыстрое локальное кэширование:**
  - Кэш всей истории покупок сохраняется в `~/Downloads/OpenRestore/purchases_cache.json`.
  - Мгновенный запуск и отрисовка библиотеки за 0.01 сек.
- **🔐 Изоляция связки ключей Direct Mode:**
  - Внедрен независимый сессионный пароль Keychain (`openrestore_passphrase_v1`), предотвращающий появление системных модальных окон macOS и блокировку 2FA кодов.
  - Полная изоляция Direct Mode от локальной базы Apple Configurator.
- **📚 Исправление синхронизации библиотеки:**
  - Исправлен баг обновления UI при скачивании по ручному Adam ID (перевод `@State` мутаций строго на Main Thread через `DispatchQueue.main.async`).
  - Автоматическая очистка поврежденных и временных файлов (<500 КБ).
- **📱 Оптимизация менеджера устройств:**
  - Корректная маршрутизация потоков данных с приоритетом USB-кабеля над локальной сетью Wi-Fi.
