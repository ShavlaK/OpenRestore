# 📦 OpenRestore — История версий (Changelog)

## [v1.5.0] — 2026-08-28

### 🚀 Ключевые нововведения
- **Нативное macOS SwiftUI приложение:** Полный переход на высокопроизводительное нативное приложение с современным интерфейсом и поддержкой macOS Sonoma / Sequoia.
- **Полная автоматизация Apple Configurator:**
  - Адаптивный поиск и выбор подключенных устройств через Accessibility API.
  - Асинхронное ожидание фильтрации App Store и гарантированный клик по кнопке «Add» / «Добавить» (с поддержкой аппаратных сигналов `Return`).
  - Фоновый перехватчик системных диалогов: автоматическое нажатие «Skip App» / «Stop» на окнах замены (`already exists`), исключающее застревание очереди.
- **Пакетная выгрузка всей библиотеки (Batch Download):**
  - Возможность в один клик скачать 10, 20 или 50 приложений подряд из истории покупок Apple ID.
  - Полная пошаговая изоляция и автоматическая очистка временных состояний между приложениями.
- **Интерактивный установщик IPA на iPhone:**
  - Модальное окно установки с живым стримингом логов в реальном времени.
  - Точный прогресс-бар передачи данных по прямому USB-каналу.
  - Встроенная автовалидация и распаковка вложенных IPA-структур перед отправкой на устройство.
  - Гарантированная защита данных (Shield Guarantee): личные файлы, фото и существующие приложения не затрагиваются.
- **Умная Библиотека IPA:**
  - Хранение официальных FairPlay DRM пакетов.
  - Мгновенная установка любого сохраненного приложения в 1 клик.
- **Интегрированный сертификат разработчика:**
  - Автоматическая подпись при сборке постоянным сертификатом для сохранения выданных разрешений Accessibility (TCC) в macOS.
